# Moneyfy

A mobile application project for managing personal finances.

## Overview
This project contains the Android app source code and related configuration for the Moneyfy application.

## Project Structure
- `app/` - Main Android application module
- `gradle/` - Gradle wrapper and version catalog configuration
- `build.gradle.kts` - Root Gradle build configuration
- `settings.gradle.kts` - Gradle settings

## Requirements
- Android Studio
- JDK 17 or compatible
- Android SDK with required platform tools

## Getting Started
1. Open the project in Android Studio.
2. Let Gradle sync the project.
3. Connect an Android device or start an emulator.
4. Run the app configuration from Android Studio.

## Build
```bash
./gradlew assembleDebug
```
